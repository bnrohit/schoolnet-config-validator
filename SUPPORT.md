# Support SchoolNet Config Validator

SchoolNet Config Validator is intended to remain **free and open source** for schools, public-sector IT teams, network engineers, students, and the wider community.

If the project saves you time, helps prevent an outage, improves troubleshooting, or is useful for your organization, you can optionally support ongoing development.

## What community support helps fund

Contributions can help with:

- ongoing maintenance and bug fixes
- multi-vendor parser and diagnostic coverage
- testing against more platforms and configurations
- documentation, examples, and training material
- hosting and development infrastructure
- security hardening and dependency maintenance
- accessibility and UI improvements
- community-requested features

## Open-source pledge

Support is always optional.

- SchoolNet remains open source under its existing license.
- Core features are not locked behind a donation.
- Donors do not receive privileged diagnostic access or hidden capabilities.
- Donations do not change the safety-first, review-first operating model.
- Community contributions are voluntary project support and are **not represented as tax-deductible charitable donations** unless the maintainer later establishes and documents an applicable charitable status.

## Stripe support

A Stripe-hosted donation checkout is being prepared so that payment-card information is handled by Stripe rather than by SchoolNet or GitHub.

**Live donation link status:** not yet published.

The connected Stripe account used during development is currently a **sandbox/test account**, so the repository intentionally does not publish that test link as if it accepted real donations. Once the maintainer enables a live-mode Stripe account, this page and GitHub funding metadata can be updated with the production Stripe donation URL.

When enabled, the intended Stripe checkout will be a **pay-what-you-want, one-time contribution** with a clear statement that support is optional and that the projects remain free and open source.

## Other ways to help

You can also support the project without donating by:

- reporting reproducible bugs
- contributing sanitized vendor configuration examples
- improving documentation
- adding tests
- contributing vendor-specific read-only command profiles
- sharing the project with other school and network IT teams

Thank you for helping keep practical network-engineering tools accessible to the community.
